# Reviewed Visual Baselines

This directory is the version-controlled approval boundary for deterministic
reference screenshots.

Baselines must be generated by the repository's supported update command,
reviewed as pull-request evidence, and committed with the product change that
justifies them. A changed screenshot is evidence to review, not a test failure
to overwrite automatically.

The supported lifecycle is:

1. Run `./scripts/propose-baselines.sh` to write ignored candidates.
2. Review every candidate PNG and `artifacts/visual/candidates/manifest.json`.
3. Run `VAIPEX_APPROVE_BASELINES=1 ./scripts/accept-baselines.sh`.
4. Commit the promoted image and approval manifest with the justified change.

`./scripts/verify-baselines.sh` proves that committed images still match their
recorded dimensions and SHA-256 digests. Never edit files in this directory by
hand.
